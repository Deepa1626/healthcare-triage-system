# 🏥 Healthcare Triage System

## 📖 Overview

The Healthcare Triage System is a full-stack web application that helps patients book appointments, report symptoms, and automatically calculates a triage priority score to assist doctors in identifying urgent cases.

This project is being developed as a final-year engineering project using industry-standard software development practices.

---

## 🚀 Tech Stack

### Backend
- Java
- Spring Boot
- Spring Security
- JWT Authentication
- Spring Data JPA

### Frontend
- React.js
- Axios
- Tailwind CSS

### Database
- MySQL
- MySQL Workbench

### Tools
- Git
- GitHub
- Maven
- Postman
